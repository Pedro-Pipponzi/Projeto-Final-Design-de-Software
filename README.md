# Projeto-Final-Design-de-Software
T-Rex game para o projeto final de Design de Software, realizado por Pedro Siqueira, Ricardo Crestana e Rodrigo Milanez



Vídeo de funcionamento: youtube.com/watch?si=hncIMX1PNo6tb-jo&v=ST4Z0wHd3aE&feature=youtu.be

Como rodar e jogar

Para baixar:
- Python 3.8 ou superior
- Biblioteca pygame
- Clone ou baixe o repositório

Para rodar:
- "python programa.py" no terminal ou rodar o 'programa.py

Controles:
- espaço ou seta para cima — pular / iniciar / reiniciar
- seta para baixa — agachar
